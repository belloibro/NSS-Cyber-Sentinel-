# NSS Cyber-Sentinel

NSS Cyber-Sentinel is a mobile application developed with Python and Flet, designed for network monitoring, system diagnostics, and educational cybersecurity assessment.

## Features

* Mobile network and system diagnostics interface.
* Cross-platform Python architecture compiled for Android.
* Automated cloud build pipeline using GitHub Actions.
